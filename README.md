# Sahem Hromos Website

A modern, responsive corporate website built for **Sahem Hromos**, designed to enhance the company’s online presence with a clean and professional user interface.

## 🚀 Overview

This project is a frontend web application developed using **React** and **Tailwind CSS**. It focuses on building a scalable, responsive, and visually appealing business website with a strong emphasis on usability and modern design principles.

The goal was to create a real-world digital solution that effectively represents the company and improves user engagement.

---

## ✨ Features

- Fully responsive design (mobile, tablet, desktop)
- Modern UI built with Tailwind CSS
- Component-based architecture using React
- Clean and structured layout for business content
- Smooth navigation and intuitive user experience
- Optimized styling with reusable utility classes

---

## 🛠️ Tech Stack

- React
- Tailwind CSS
- JavaScript (ES6+)
- HTML5

---

## 🎯 Purpose

This project was built to:
- Improve the digital presence of a family-owned business
- Gain practical experience with React and Tailwind CSS
- Strengthen frontend development and UI/UX skills
- Build a portfolio-ready real-world project
